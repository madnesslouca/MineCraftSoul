# Masmorras do MineCraftSoul

Este diretório contém a documentação e prompts para construção das masmorras do servidor.

## Masmorras Planejadas

| Masmorra | Tier | Nível Recomendado | Status | Boss |
|----------|------|----------------------|--------|------|
| **Catacumbas do Véu Rasgado** | 1 | 8 ~ 20 | Em desenvolvimento | Guardião Corrompido (placeholder) |
| Ruínas do Santuário Perdido | 2 | 20 ~ 35 | Planejada | - |
| Abismo das Almas Quebradas | 3 | 35 ~ 50 | Planejada | - |

## Como usar os prompts do MCP

1. Copie o conteúdo do arquivo `prompts/mcp/`
2. Cole no seu agente MCP (Mineflayer)
3. O agente irá construir a masmorra automaticamente
4. Depois refine manualmente com WorldEdit se necessário

## Estrutura de uma Masmorra

- **Entrada** na superfície (ruínas visíveis)
- **Múltiplos andares** subterrâneos
- **Armadilhas** variadas
- **Puzzles** de alavancas / redstone
- **Arena de Boss** no final com mecânicas interessantes
