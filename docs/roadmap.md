# Roadmap - MineCraftSoul

## Fase 1: Fundação (Semana 1-2)
- [ ] Instalar PaperMC + plugins base (AuraSkills, MythicMobs, ItemsAdder, PlaceholderAPI)
- [ ] Configurar sistema de stats custom (Força, Constituição, Destreza, Inteligência)
- [ ] Criar sistema de pontos de atributo por level up
- [ ] Testar menu de distribuição de pontos (DeluxeMenus)

## Fase 2: Conteúdo Inicial (Semana 3-4)
- [ ] Projetar e criar o primeiro boss (3 fases, estilo Souls)
- [ ] Criar primeira masmorra pequena (com traps e puzzle)
- [ ] Implementar sistema de Almas/Eco (morte = drop almas no local)
- [ ] Criar 3-4 skills combinadas iniciais

## Fase 3: Expansão (Mês 2)
- [ ] 2ª e 3ª masmorra
- [ ] Mais 4 bosses
- [ ] Sistema de gear com requisitos de atributo
- [ ] Quests iniciais com BetonQuest

## Fase 4: Polimento (Mês 3+)
- [ ] Balanceamento profundo
- [ ] ModelEngine para bosses bonitos
- [ ] Integração com MCP para construção automática de masmorras
- [ ] Testes multiplayer
