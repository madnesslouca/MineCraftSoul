# Prompt Template para Claude - Boss MythicMobs

Use este template quando for gerar YAMLs de bosses complexos:

```
Crie um boss MythicMobs completo com as seguintes características:

Nome: [Nome do Boss]
Tema: [Dark Fantasy / Corrupção de Almas]
Número de Fases: 3

Fase 1:
- Descrição do comportamento
- Skills usadas
- Condições de transição (ex: aos 70% de vida)

Fase 2:
...

Fase 3:
...

Mecânicas Souls-like desejadas:
- Telegráficos claros (partículas + sons)
- Padrões aprendíveis
- Arena que muda
- Adds em fases específicas

Gere o YAML completo e bem comentado do MythicMobs.
```
