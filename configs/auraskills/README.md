# Configuração do AuraSkills

Esta pasta contém os arquivos de configuração do plugin **AuraSkills** para o sistema de progressão do MineCraftSoul.

## Estrutura

- `stats.yml` → Definição dos stats custom (Força, Constituição, etc)
- `skills/` → Habilidades que o jogador pode desbloquear
- `menus/` → Menus de distribuição de pontos (via DeluxeMenus)
