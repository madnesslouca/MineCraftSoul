# ItemsAdder - Itens Customizados

Esta pasta contém todos os itens customizados do projeto MineCraftSoul usando o plugin **ItemsAdder**.

## Estrutura

- `items/` → Arquivos .yml com definições de itens
- `armors/` → Armaduras custom (se usar resourcepack)
- `weapons/` → Armas custom

## Como usar

1. Instale o plugin **ItemsAdder** no servidor.
2. Copie a pasta `itemsadder` inteira para:
   ```
   plugins/ItemsAdder/
   ```
3. No console:
   ```
   /ia reload
   ```

## Itens do Boss Guardião Corrompido

Os itens abaixo são drops do primeiro boss e usam os stats do sistema de AuraSkills (Força, Constituição, Destreza, Inteligência, Sabedoria).

- **Lâmina do Véu Corrompido** → Arma melee híbrida (Força + Inteligência)
- **Elmo do Guardião** → Tanque (Constituição)
- **Fragmento do Véu Rasgado** → Material de crafting raro
